## 4. Retargeting, animation workflow, AI motion

- UE 5.8: Live Link Hub is now production-ready (device control, synchronized recording, multi-camera monitoring); Control Rig Dynamics solver; MCP plugin for LLM-to-engine control ([forum release post](https://forums.unrealengine.com/t/unreal-engine-5-8-released/2729274), [80.lv](https://80.lv/articles/unreal-engine-5-8-is-out-today-with-big-optimization-improvements-and-mesh-terrain/)). Official MCP docs are reported incomplete, with toolsets needing manual enabling (same). Take Recorder / Sequencer 5.8 specifics: UNVERIFIED (only hotfix fixes seen: [5.8.1](https://forums.unrealengine.com/t/5-8-1-hotfix-released/2738864), [5.8.2](https://forums.unrealengine.com/t/5-8-2-hotfix-released/2746335)).
- 5.7 added IK Retargeter improvements (foot contact, squash/stretch, self-collision) ([CGChannel](https://www.cgchannel.com/2025/11/unreal-engine-5-7-five-key-features-for-cg-artists/)). Treat IK Rig + Retargeter as the standard bridge between any skeleton (Tripo, CC, VRM) and your Live Link streams. **ADOPT**.
- **Text-to-motion:** NVIDIA Kimodo-based community UE plugin retargets via IK Rig; weights are ~9.3 GB under NVIDIA Open Model License plus Llama 3 licence ([forum](https://forums.unrealengine.com/t/altercode-text-to-anim-local-ai-text-to-animation/2838544)). Third-party, one source: **WATCH/TRIAL** offline only, licence review needed.
- **Audio-to-gesture:** NVIDIA Omniverse Audio2Gesture exists ([docs](https://docs.omniverse.nvidia.com/extensions/latest/ext_audio2gesture.html)); licence and UE route UNVERIFIED. **WATCH**.
- MotionGPT, HY-Motion: nothing found, UNVERIFIED.

## 5. Multi-performer / LBVR networked capture

- UE 5.7 introduced a Live Link Broadcast Component (UE as network animation source) ([5.7 summary](https://forums.unrealengine.com/t/unreal-engine-5-7-released/2673913)); overlaps Open3DStream. Live Link Hub's synchronized recording helps timecode for takes. Xsens and Reallusion expose timecode ([Xsens](https://www.xsens.com/integrations/unreal-engine), [Reallusion](https://www.reallusion.com/ICLONE/live-link/unreal-engine/feature.html)).
- Open3DStream fit (inference, no vendor data): it is the transport for relaying suit, Quest and phone streams to a server with one clock; keep it. Required work: per-performer subject naming, a shared clock (PTP/NTP plus timecode stamping), and merging body+face into one subject (UE 5.7 MetaHuman rule). Measured latency for LBVR: no source found, UNVERIFIED; measure end to end.

## Key risks

1. **Licence**: MetaHuman markerless runtime models and Fab plugin EULA have no Epic answer for shipped games; keep markerless/MHA as editor-only. MetaHuman runtime/mobile terms unconfirmed (licence page unreadable). Audio2Face weights are gated.
2. **Mobile/Quest budget**: MetaHuman mobile LOD 3 / 2048 textures still heavy for Quest; use VRM/CC-lite or custom low-poly avatars for standalone.
3. **Plugin lag**: Reallusion, Xsens, Neuron, Audio2Face plugins show support only up to UE 5.3-5.7; 5.8 unconfirmed.
4. **Lock-in/agent surface**: Reallusion and cloud mocap (Move.ai) are GUI/credit based; MetaHuman has the only official agent surface (batch API, MCP).

## Recommendation (summary)

ADOPT: MetaHuman 5.8 (PC/LBVR-PC), Live Link Face + MHA, Quest Movement SDK for player avatars, IK Retargeter, VRM path, Open3DStream. TRIAL: CC 5.2 (after 5.8 plugin check), Tripo + Mesh to MetaHuman, Xsens or Rokoko suit, Audio2Face-3D, MHA markerless (editor only). WATCH: Vicon/OptiTrack, Move.ai, text-to-motion, MediaPipe. SKIP: Faceware, LiveFace, Rokoko Face.
