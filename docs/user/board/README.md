# Board

This area is a project's Board tab and the page of each piece of work on it. Everyone on the project who uses the dashboard can open it. Jordan, the producer, and Morgan, the director, add work and choose its owner. Riley, the artist, and Drew, the sound designer, open their work there to read feedback and send versions.

## The ideas you need

- A piece of work is anything that goes through a gate. Each piece of work has one stage, one owner and its versions.
- Each piece of work is In progress, Waiting for review, Blocked or Done. Nobody sets these states by hand: they change when work is sent, decided, withdrawn or handed on, and when approvers change.
- Every piece of work keeps all its versions. Each time it is sent for review, the file becomes its next version.
- Feedback is written on a version and shown beside it. Adding feedback does not decide anything: only the approver's decision does.

## Pages

In the order a user needs them:

- [Board](board.md): see where every stage and piece of work stands, show only blocked work, add work, change its owner, and remove work added by mistake.
- [Versions and feedback](versions-and-feedback.md): see a piece of work, give feedback on a version, send a revised version, compare two versions, and restore an earlier one.
