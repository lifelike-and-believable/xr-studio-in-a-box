# XR Studio

XR Studio is the dashboard a production team uses to run a live or interactive XR production. Today it holds the project record: who is on each project and with which roles, the project's and the organisation's facts, who approves each stage, the work sent for review with its versions and feedback, and a log of every change. People decide at every gate. Agents and the tools for making work come in later releases.

## The areas

- [Signing in and your account](signing-in/README.md): accept an invitation, sign in with an email link or a passkey, and sign out.
- [What needs you](what-needs-you/README.md): see what is waiting for you on all your projects, with the next step for each.
- [Projects](projects/README.md): find and move between your projects, start a project, and create or change an organisation.
- [Review](review/README.md): send work for review, see what you sent, and decide the items waiting for you.
- [Board](board/README.md): see every stage and piece of work on a project, add work, and read, compare and restore versions with their feedback.
- [Facts](facts/README.md): record a project's facts once, and read, compare and restore their earlier versions.
- [People and approvers](people/README.md): add people to a project, set their roles, and name who approves each area.
- [Activity](activity/README.md): read who changed what, and when, on a project or an organisation.
- [Organisations](organisations/README.md): keep the company facts every project reads, and the list of identifier formats that keeps bank and tax numbers out.
- [Help and trial copies](help/README.md): open help for the page you are on, follow a tutorial for a task, and try a change in a trial copy with made-up data.

## Where to start

- If you have just been invited, start with [Signing in and your account](signing-in/README.md): open the link in your invitation email.
- If you are Jordan, the producer, start with [Projects](projects/README.md): start a project, then add people on its People tab.
- If you are Morgan, the director, start with [Review](review/README.md): open the project's Review tab and decide the items waiting for you.
- If you are Riley, the artist, start with [What needs you](what-needs-you/README.md): find the work assigned or returned to you, then send it for review.
- If you are Sam, the technical artist, start with [What needs you](what-needs-you/README.md): see what waits for your decision as a delegate, and what is assigned to you.
- If you are Drew, the sound designer, start with [What needs you](what-needs-you/README.md): read the panel that says how work moves on your project, then open your first piece of work.
- If you were given a link to a trial copy, start with [Help and trial copies](help/README.md): open Try XR Studio and choose a tutorial.
