# Activity

This area is the activity log of a project and of an organisation. Jordan, the producer, Morgan, the director, and Sam, the technical artist, can read a project's activity. People who look after an organisation can read the organisation's.

## The ideas you need

- Every change on a project is recorded in its activity log: who did what, and when. It records changes, not who opened which page.
- Nobody can edit or remove an entry.
- An entry says what was saved, never the text or figures of a fact.
- Organisations have their own activity log for changes to the organisation, its facts and its identifier formats.

## Pages

In the order a user needs them:

- [Activity](activity.md): read a project's activity, filter it by person, area and date, and read an organisation's activity.
