# Projects

This area covers finding your projects, moving between them, and setting up a project and its organisation. Everyone who uses the dashboard finds their projects here. Jordan, the producer, and Morgan, the director, start projects and edit them.

## The ideas you need

- A project holds one show's brief and work. Every project belongs to an organisation.
- On a solo production you do not need to create an organisation first: when you start a project, XR Studio makes one for you.
- A project has an owner, who gets the Director and Producer roles when it starts. An organisation has people who look after it, who can rename it and change who looks after it.
- You see only the projects you are on, and inside each project only what your roles there allow.
