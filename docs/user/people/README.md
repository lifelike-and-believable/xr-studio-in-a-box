# People and approvers

This area is a project's People and Approvers tabs. Jordan, the producer, and Morgan, the director, add people, set their roles and name the approvers. Everyone else on the project who uses the dashboard can see who is on it and who approves what.

## The ideas you need

- Everyone on a project has one or more roles. A role decides what the person can see and do.
- Holding a role never gives an approval. Approvers are named separately, per project.
- The gates are grouped into four areas. Each area has an approver and, if you want one, a delegate. Either of them can decide any item in the area.
- Four protected approvals each have one holder, a named person, who cannot hand it on. When a project starts, its owner holds every approval.

## Pages

In the order a user needs them:

- [People and roles](people-and-roles.md): see who is on a project, add a person, send an invitation again, change someone's roles, and remove someone.
- [Approvers](approvers.md): see who approves what, name an approver and a delegate for an area, and name the holder of a protected approval.
