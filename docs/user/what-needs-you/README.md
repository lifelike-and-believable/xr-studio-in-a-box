# What needs you

This area is the first page you see when you sign in. It lists what is waiting for you on all your projects and says the next step for each. Riley, the artist, and Drew, the sound designer, find their work here. Morgan, the director, and Sam, the technical artist, find the work that waits for their decision.

## The ideas you need

- Each stage has a gate: the point where a named person must accept your work before it moves on.
- The page has up to four lists: work for your decision, work returned to you, work assigned to you, and work you sent that is waiting for others. You only see the lists that have something in them.
- You only see work on projects you are on, and only what your roles there allow.
- The page checks for changes every 15 seconds while it is open, so you do not need to reload.

## Pages

In the order a user needs them:

- [What needs you](what-needs-you.md): find what to do next, see how work moves on a project you are new to, and see what changed.
