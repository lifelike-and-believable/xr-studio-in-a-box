# Facts

This area is a project's Facts tab. Jordan, the producer, and Morgan, the director, record and edit the facts. Every role that uses the dashboard can read them, except the budget, which only the director and producer see.

## The ideas you need

- A project's facts are recorded once: the description, plan, budget, credits, collaborators, schedule, work samples and capacity.
- Every save is kept as a version. Restoring an earlier version saves it as a new version, so no version is removed or changed.
- Facts can be read by agents, so text that looks like a bank or tax number is not saved.
- The Facts tab also shows the organisation's legal name and bio, which every project in the organisation reads. You edit those on the organisation's page.
