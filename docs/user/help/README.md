# Help and trial copies

Help is where you read about a page and follow a tutorial for a task. Everyone who uses XR Studio uses it. A trial copy is a separate copy of XR Studio with made-up people and data, where Morgan, the director, tries a change before a production relies on it.

## The ideas you need

- Help follows the page you are on. It opens the help for that page, or for that part of XR Studio.
- A tutorial is a set of steps for one task, named for the task. You follow it in XR Studio with your own account.
- A trial copy holds nothing real, and no email leaves it. The XR Studio your production uses is not a trial copy and has no page for one.

## Pages

In the order a user needs them:

- [Help and tutorials](help-and-tutorials.md): open help for the page you are on, and follow a tutorial.
- [Trying XR Studio](trying-xr-studio.md): start a tutorial in a trial copy and sign in as its made-up people.
