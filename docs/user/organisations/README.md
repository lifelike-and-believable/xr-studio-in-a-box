# Organisations

This area is an organisation's page: its facts, its standard work samples and its identifier formats. The people who look after an organisation keep them: Jordan, the producer, when Jordan created it or is listed as looking after it. Everyone on the organisation's projects who uses the dashboard can read the general facts.

## The ideas you need

- An organisation keeps the company's own facts, such as its legal name and bio. They are recorded once, and every project in the organisation reads them.
- Only the people who look after an organisation can edit its facts and its list of identifier formats.
- Facts and work samples can be read by agents, so XR Studio checks text against the organisation's identifier formats before saving it, and stops anything that matches.
- If ordinary text only looks like an identifier, you can confirm that it is not one and save it. The confirmation is recorded with your name and the time.
