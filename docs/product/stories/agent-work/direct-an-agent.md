# Direct an agent in conversation

As Morgan, the director, I want to direct an agent on a project task in conversation so that I can steer drafts early without leaving the conversation.

## Acceptance criteria

- Morgan can ask an agent to do a task on a named project, in chat.
- The agent says what it will do, and reports what it did.
- Work the agent produces goes to the review queue where a gate applies.
- If the agent cannot do the task, it says why in plain language.
