# Add a step, integration or check

As Sam, the technical artist, I want to add a workflow step, integration or check without changing the core so that I can fix a problem once for every project.

## Acceptance criteria

- Sam can add a step, integration or check without modifying the core.
- The addition is versioned and reviewed like other project work.
- Sam can see which version of an addition a project is using.
- A failing addition reports why, in a way Sam can act on.
