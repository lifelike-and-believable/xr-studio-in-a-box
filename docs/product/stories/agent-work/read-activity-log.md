# Read what agents did

As Morgan, the director, I want to read a log of every agent action so that I know what was done in the project's name.

## Acceptance criteria

- Morgan can open a log of every agent action on a project.
- Each entry names the project, stage, tool and the person who requested or approved it.
- Morgan can filter the log by agent, stage or date.
- Nobody can edit or remove an entry.
