# Read what agents did

As Sam, the technical artist, I want to read a log of every agent action so that I can see why an agent failed and fix the cause once.

## Acceptance criteria

- Sam can open a log of every agent action on a project.
- Each entry names the project, stage, tool and the person who requested or approved it.
- Sam can filter the log by agent, stage or date.
- Nobody can edit or remove an entry.
