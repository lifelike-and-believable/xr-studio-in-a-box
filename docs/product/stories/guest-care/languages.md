# Offer several languages without rework

As Morgan, the director, I want captions, on-screen text and dialogue kept apart from the build so that a show can offer another language without rebuilding the same things.

## Acceptance criteria

- Captions, on-screen text and dialogue are kept apart from the build, one set for each language the show offers. A language can be added or changed without a new build.
- Each language's set is versioned. An agent can draft a translation, marked as a draft. A person who reads the language checks it, and the director or their delegate approves it in production mode (story-show-safety-switch-modes) before it reaches a session with guests. An agent cannot approve it.
- A signed language is offered as a sign-interpreted view (story-guest-care-access-options), performed by a person and never generated by AI.
- Guests choose a language in the pre-show (story-guest-care-standard-pre-show). Before the switch to show mode, the director or their delegate sees in text each item missing from each language. A guest who meets a missing item sees it in the show's main language.
- The story is tested with two languages, one added after the build is made with no rebuild, in the Unreal Editor run as a standalone game on the budget file's test device (story-asset-checks-check-against-budget).
