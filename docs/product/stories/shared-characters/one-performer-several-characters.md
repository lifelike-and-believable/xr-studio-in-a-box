# Drive several characters from one performer

As Kai, the performer, I want to drive several characters at once so that I can play several creatures in one scene.

## Acceptance criteria

- One performer's source can be assigned to channels of two or more characters at once, as in story-live-puppet-assign-channels.
- A technical artist can place each character, so they do not overlap, without code.
- Each character's measured delay stays within the delay target (story-live-puppet-measure-delay).
- The capture crew sees which characters each performer drives.
