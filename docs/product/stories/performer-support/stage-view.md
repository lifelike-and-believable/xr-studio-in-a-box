# See the virtual character from the stage

As Kai, the performer, I want to see the virtual character I drive or play opposite from the stage so that I can feel the puppet respond at once.

## Acceptance criteria

- Casey can set up a stage view for a show through a monitor, a headset or another view the show sets.
- Kai can see from the stage both their own character and a character driven by someone else or by a recording.
- The delay from Kai's movement to the stage view is measured and shown, and stays within the show's delay target (story-live-puppet-measure-delay).
- For a performer in a suit with no headset, the stage view uses what the test in story-performer-support-crew-channel found they can see.
- The stage view works on the venue network with the internet off.
