# Revise an effect from feedback and send it to the gate

As Riley, the artist, I want to have an effect revised from written feedback and sent to its gate so that I see it revised with earlier versions kept, and know what the reviewer said.

## Acceptance criteria

- Riley can write feedback on an effect and get a revised version, with earlier versions kept and restorable (story-review-and-status-feedback-and-versions).
- Riley can play two versions side by side on the same proxy character in the Unreal Editor.
- Riley can send an effect to the visual effects gate. It waits for the named person or their delegate (story-review-and-status-hold-gated-hand-off), and appears in their queue with a recorded preview and its effect cost check (epic-asset-checks).
- Riley sees the reviewer's decision and written feedback beside the effect (story-review-and-status-decide-on-items). An agent can revise an effect but cannot approve it.
