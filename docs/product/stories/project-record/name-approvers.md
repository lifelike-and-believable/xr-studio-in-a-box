# Name approvers and delegates

As Morgan, the director, I want to name who approves each area, and who holds the four protected kinds of approval so that I can delegate safely and those four approvals stay with people.

## Acceptance criteria

- Morgan can name an approver and a delegate for each area of the gate list.
- The project shows who holds each of the four protected approvals: contracts and licence terms, funding, publishing and marketing, and audience-facing safety and consent.
- An AI cannot be chosen for any of the four protected approvals.
- One person can hold every role, so Morgan can run a production alone.
