# Follow a tutorial for a task

As Drew, the sound designer, I want a tutorial for the task I am trying to do, and help for the page I am on, so that I can learn XR Studio by doing the task without a technical person beside me.

## Acceptance criteria

- Every page of the dashboard has **Help**. It opens the help for the page Drew is on, or for that part of XR Studio when the page has no help of its own.
- Help starts from one page that lists the parts of XR Studio in the order a person meets them and says where each role starts.
- Each help page that describes a task links to a tutorial for it. The tutorial is named for the task, says who it is for, and says what Drew needs before starting, in XR Studio's own words: an account, a role, or an earlier tutorial.
- Drew follows the tutorial in the XR Studio the production uses, with Drew's own account. Where a step needs another person, the tutorial names them, and says before the steps which role that person has.
- The tutorial names no command, no folder and no setting. Drew does not need code or the command line to follow it.
- The same tutorials are the ones Morgan followed in a trial copy before the change was accepted (story-project-record-try-from-a-link), so what Drew reads has been tried.
- Jordan, the producer, can send a new person the link to a tutorial, and it opens after they sign in.
