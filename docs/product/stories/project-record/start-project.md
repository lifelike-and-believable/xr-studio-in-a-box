# Start a new project

As Morgan, the director, I want to start a project with a name, a brief and an owner so that I have one place to take a brief towards a show.

## Acceptance criteria

- From the web dashboard, Morgan can create a project by giving a name, a brief and an owner.
- The new project appears in Morgan's project list with those details.
- A project cannot be created without a name and an owner, and Morgan is told what is missing.
- The project's own facts start empty, with none carried over from another project. The facts of the organisation it is placed in are read in, not copied (story-project-record-set-up-organisation).
