# See the same project state everywhere

As Morgan, the director, I want to see the same project state in the dashboard and in chat so that I can work from either without wondering which is right.

## Acceptance criteria

- A change made in the dashboard appears when Morgan asks about it in chat, and the reverse.
- Morgan sees only what their role allows on both surfaces.
- The dashboard can be used by keyboard and with a screen reader, and meets WCAG 2.2 AA.
