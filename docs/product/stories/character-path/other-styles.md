# Make any character style through the same path

As Morgan, the director, I want stylised, creature and abstract characters made through the same path so that I take a brief to a running show without rebuilding the path for each production.

## Acceptance criteria

- Morgan, or their delegate, chooses one of three styles in the character brief: a stylised or illustrated character; a creature, animal or spirit; or an abstract or energy form. Each style uses the same stages and gates (story-character-path-design-drafts, story-character-path-mesh-and-rig), with no extra stage.
- A creature style is a character a performer drives. It becomes an autonomous creature (story-crowds-and-creatures-add-creatures), with that story's count limit, only when it is given a behaviour specification (story-behaviour-and-limits-write-specification) and added as one.
- A creature whose body does not match the performer's is driven through a mapping (story-shared-characters-map-a-different-body) or the nearest body plan (story-nearest-body-retargeting-match-nearest-body-plan), not by hand-rigging per source.
- An abstract or energy form with no mesh is a character. Its mesh and rig stage makes the form and the values that drive it, the same gate reviews it, and Sam can drive those values through a parameter mapping (story-shared-characters-parameter-mapping).
- The realistic human style (REQ-content-2), including a performer's likeness, comes later, because the first show uses stylised characters (approver's decision). It will be generated only under a confirmed agreement that allows that AI use (story-session-recording-check-agreement). In Layer 3 it is not offered in the brief.
- The story is accepted when a stylised character, a creature and an abstract form have each passed both gates and been driven by a recorded portable inertial suit take (story-session-recording-record-and-replay).
