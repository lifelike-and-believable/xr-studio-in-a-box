# Sam, technical artist or pipeline engineer

<!-- Stories link to a section, for example persona-technical-artist#goals. -->

## Goals

- Add or change workflow steps, integrations and checks without modifying the core.
- Replace an external tool through its adapter without rewriting the workflow around it.
- See why an agent, check or build failed, and fix the cause once for every project.
- Set up rigs, retargeting and capture mappings, including for characters whose bodies do not match the performer's.
- Keep engine and plugin versions under control across targets.
- Make sure that a show keeps running when agents and the internet are gone.

## Skills and tools

- Unreal Engine, C++ and Blueprint, Python, Blender, and rigging and retargeting.
- Git, large-asset version control, and build automation.
- Agents, scripting interfaces and MCP servers.
- Reads logs and writes integrations. Comfortable with the command line.

## Context of use

Works at a workstation in the Unreal Editor, code and chat with the agent. Often the person called when a generated asset fails a check or an integration breaks during rehearsal. May be in-house, shared or hired per project, so may arrive with no knowledge of how earlier projects were set up.

## Frustrations

- Tools, engine versions and plugins change, and a change in one breaks hand-offs in others.
- One-off show code cannot be reused on the next production.
- Generated assets arrive with naming, topology, rig or material problems that are found late **[assumed]**.
- Failures that only appear on real consoles or capture hardware, which are unavailable until rehearsal **[assumed]**.
