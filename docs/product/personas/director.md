# Morgan, director and approver

<!-- Stories link to a section, for example persona-director#goals. -->

## Goals

- Take a brief to a running, tested show without rebuilding the same things for each production.
- Keep the creative bar high: see drafts early, steer them, and decide what is good.
- Approve quickly, so that review does not become the pipeline's limit.
- Delegate an area to a named person when a project has one, and keep the four kinds of approval that never go to an AI with people.
- Spend less personal time on funding applications, budgets and reports, which today are mostly written by hand.
- Run a whole production alone when there is no team.

## Skills and tools

- Deep experience of live XR, motion capture and Unreal Engine productions.
- Directs agents in conversation, and reviews through a queue with previews.
- Comfortable with technical detail, but wants decisions presented as choices, with the evidence attached.
- Works across the Unreal Editor, the web dashboard and chat.

## Context of use

Works on several things at once, from a studio desk or a rehearsal room, often between other tasks. Reviews come in bursts, so items need to be batched and readable at a glance. In a solo production, the same person is also the producer, the show operator and sometimes the performer, and may be running the show while performing in it.

## Frustrations

- Each show rebuilds work done for the last one, and each stage has its own tools and hand-offs.
- Character design, meshing and rigging take the most time, then environments, then show control and cues.
- Nearly every stage needs a person's approval, so a slow or unclear queue stops everything.
- Funding is the business area that hurts most, across the whole cycle from finding programs to final claims.
- The same project facts are retyped for production documents, applications and reports.
